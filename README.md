# Observe Around

Görme engelli kullanıcılar için çevre algılama ve yönlendirme projesi.

## Klasörler
- **[`faz0/`](faz0/README.md)** — Aktif çalışma. Gövdeye takılan titreşimli
  yön bandının 2B simülatörü ve donanımdan bağımsız titreşim katmanı.
  Bağımlılık yok, sadece Python standart kütüphanesi.
- **[`arsiv/`](arsiv/README.md)** — İlk sürüm (SEE): YOLOv8 ile nesne algılama,
  pose estimation ve stereo derinlik haritası.

İleriki fazlar için değerlendirilen fikirler (ROS 2 vb.):
[GELECEK_PLANLAR.md](GELECEK_PLANLAR.md)

## Hızlı Başlangıç
```bash
cd faz0
python run_sim.py
```
